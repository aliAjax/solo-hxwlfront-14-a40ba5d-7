# 航班装载与重心校核台

面向货运航空配载员的航班装载与重心校核工具（教学简化数据，机型 B747-400F）。

- 行业：航空货运 / 配载平衡
- 技术栈：React、Vite、TypeScript、Ant Design、zustand、echarts
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 浏览器验证：`npm run verify`（构建 + Playwright 自动化测试）

## 功能

- **机型与燃油录入**：使用空重/空机力臂、6 个油箱（含水平安定面配平油箱）油量与容量、按耗油顺序供油；支持油箱间转油配平。
- **货舱隔位**：主货舱 M1–M8、前下货舱 F1–F4、后下货舱 A1–A4、散货舱 B1；每个舱位有力臂、限重、尺寸、温控电源、危险品许可与集装器类型限制，每个货舱有累计限重。
- **集装器（ULD）装载**：按重量、尺寸、温控、危险品隔离规则落位；超限、超容、类型不符、无温控电源、隔离冲突时**不能落位**，并给出具体舱位号与原因。
- **危险品隔离**：简化 IATA 隔离表（1 类与所有类隔离、5.1 类与 2.1/3/4.2/4.3 类隔离、4.3 与 8 类隔离等），同舱冲突拒绝落位。
- **多航段重量与重心**：PEK–PVG–HKG–SIN 三航段，按各段在机业载与燃油消耗分别计算 ZFW/TOW/LDW 及重心（%MAC），逐级联动的剩余燃油、MTOW/MLW/MZFW 与重心包线判定，超限给出配平建议。
- **重心包线图**：echarts 绘制前后限包线、结构限重线，逐航段 ZFW/TOW/LDW 描点（正式方案实心、演练空心、超限红色）。
- **草案 / 正式方案两段流程**：草案随时可改；点击“锁定为正式方案”时重新校验全部放置、危险品隔离、重量重心与燃油规则，任一项不通过即拒绝锁定；锁定后临时加货、转油、航段调整只能进入演练区。
- **演练区**：演练改动记录为操作清单，校验全部通过才能“确认并入正式方案”，未确认改动不影响正式方案，可一键放弃回滚。

## 浏览器验证（Playwright）

`tests/verify.spec.mjs` 覆盖：

1. 页面与包线图渲染；
2. 放置约束：单舱位超限、舱段超容、类型不符、无温控电源、舱位占用——均拒绝并指出舱位；
3. 危险品隔离：同舱冲突拒绝并指出舱位、异舱允许、1 类与所有类隔离、散货舱禁危险品；
4. 前后舱配平：集装器后移重心后移量正确、燃油配平触发后限报警与配平建议、可恢复；
5. 重心边界：演示方案全绿、过度前装触发前限报警；
6. 草案锁定校验：错误草案（重心出包线 / 燃油不足）锁定被拒，修正后锁定成功；
7. 多航段燃油变化：逐段累计重量/重心精确断言、改耗油逐级联、燃油不足报警；
8. 演练区隔离：锁定后直改被拒、演练不进正式方案、校验通过才能确认、放弃回滚、校验失败禁止确认。
